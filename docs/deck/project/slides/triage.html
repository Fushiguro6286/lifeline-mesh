For rescue teams

Fifty messages become one ranked list.

Merge and rank

Reports of the same place are merged. Ranked by urgency, trapped and medical first, people, distance and waiting time. Plain code, unit-tested.

Situation report

Code counts everything; the model writes three lines a team leader can read aloud. Any number not in the counts, and the template is shown instead.

Ask the mesh

"Any medical cases?" The answer cites alerts like #2. No citation, a wrong one, or a slow model: the rule-based answer is used.
