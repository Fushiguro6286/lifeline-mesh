Header · 19 bytes

Type · random message ID (spots duplicates) · random sender ID, never a phone number · hops left (TTL) · hops so far · time

Alert · 39 bytes

Latitude and longitude to 0.1 m (00 C5 F5 BF = 12.973503) · accuracy in 10 m steps · needs · urgency · people · the note in UTF-8

Lifeline Mesh · 9

A real example: "Water rising, 4 on the roof", trapped plus medical, 4 people, urgent. The latitude 12.973503 is stored as the whole number 12973503 in 4 bytes, so nothing is lost; GPS accuracy, not the packet, is the limit. Each relay changes only two bytes: TTL down, hops up. Unit tests cover every packet type, Hindi and Kannada notes and damaged packets.
