Lifeline Mesh · 10

Controlled flooding: simple, robust, no routing tables to break. On every new connection both phones swap a summary of recent message IDs and send only what the other lacks. Each phone waits 50 to 300 ms before passing a message on, so copies don't collide. A volunteer walking between two groups carries stored alerts across.
