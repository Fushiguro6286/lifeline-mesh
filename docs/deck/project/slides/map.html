For rescue teams

A map that works with no internet at all.

Offline tiles

MapLibre reads a Bengaluru map file stored on the phone. Alerts are coloured by urgency.

Road routes

A* on the map's own roads, avoiding reported blocks, with minutes on each leg. Boats go straight. Always marked as an estimate.

Honest positions

Each position has an accuracy circle. GPS readings are averaged and jumps ignored; vehicles are placed on the road they are on.

Always a fallback

If the map can't load, a simple Rings view shows the same alerts by distance and direction.

Lifeline Mesh · 14

GPS works with no signal; it only listens to satellites. Accuracy is sent inside the packet in 10 m steps, rounded up, so a position is never claimed to be better than it was. When a phone with an open alert finds internet, it also sends its position through the server, where online teams see it marked "via internet".
