How a message crosses the mesh

The mesh looks after itself.

Low-battery survival mode

Below 20% a phone beacons less often and drops low-value traffic. Below 10% it passes on only urgent alerts, replies and check-ins.

Relay gap finder

Shows where to stand a volunteer phone to reach a cut-off group, and which single phone the whole mesh depends on.

Mesh path

Draws the chain of phones an alert travelled through, from the person in need to the rescue team.

Road block reroute

A "road blocked" report travels the mesh and every team's route avoids it straight away.

Survival mode matters because in a flood nobody can charge a phone. The gap finder uses the last positions heard over the mesh; the weak point is a graph articulation point, the one phone whose loss splits the network. Held packets go out as soon as the phone is charging. In the simulation, "Block the road ahead" makes the ambulance route go around the block.
